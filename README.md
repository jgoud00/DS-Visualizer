# Data Structure & Algorithm Visualizer

A modern, interactive frontend web application designed to help students and developers learn Data Structures and Algorithms through dynamic animations and visual representations.

## ✨ Features

* **Step-by-Step Execution**: Pause, play, step forward, and step backward through algorithm execution.
* **Pseudocode Tracking**: Follow along with the active line of pseudocode as the algorithm runs.
* **Complexity Analysis**: View time and space complexity for each operation.
* **Modern Aesthetic**: Built with a sharp, developer-tool-inspired design system featuring dark/light modes.
* **Responsive Layout**: Works seamlessly across desktops and tablets.

### Supported Visualizers

* **Arrays**: Insert, Delete, Linear Search
* **Stacks**: Push, Pop, Peek
* **Queues**: Enqueue, Dequeue, Peek
* **Linked Lists**: Singly Linked List (Insert, Delete, Search, Reverse)
* **Binary Search Trees (BST)**: Insert, Delete, Search, Traversals (Inorder, Preorder, Postorder)
* **Graphs**: BFS, DFS, Detect Cycle, Connected Components
* **Sorting Algorithms**: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort
* **Searching Algorithms**: Linear Search, Binary Search

## 🛠️ Technology Stack

* **Core**: React 19, JavaScript (ES6+), HTML5, CSS3
* **Build Tool**: Vite
* **Animations**: Framer Motion
* **Layouts & Math**: D3.js (d3-hierarchy, d3-force)
* **Icons**: Lucide React
* **Architecture**: Pure JS generator functions for algorithm logic, decoupled from React state.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jgoud00/DS-Visualizer.git
   cd DS-Visualizer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
